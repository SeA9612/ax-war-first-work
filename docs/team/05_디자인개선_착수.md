# 디자인 개선 단계 착수 — 2026-11-11

## 목표
배포된 운영 시스템 웹페이지(https://axwar-assignment-xjdg.axhub.app)의 **화면 디자인과 사용 효과를 개선**한다. 심사위원·시연 영상 시청자가 "판정 → 근거 → 승인 → 작업·상태 갱신" 흐름과 [실제 작동]/[모의] 구분을 한눈에 이해하게 만드는 것이 목적이다.

## 바꾸면 안 되는 것 (기능 동결)
- 서버 로직·규칙 J1~J8·API·판정 수치·시나리오 기대값. `npm test` 57건 전부 통과 유지.
- 탭 이름·주요 버튼 문구(시연 대본이 참조): 대시보드 / 사건(Case) / 이벤트 입력 / 재공급 계획 / 확장 ON/OFF 비교 / 시연 시나리오 / 감사기록 / 데이터 출처, '초기화'. 바꿔야 하면 팀장 승인 후 대본 동시 수정.
- 근거 태그 [원본]/[도출]/[가정]/[모의]/[미확인], '모의 AI' 표시, 공유 환경 안내, 기준일 표시.
- 비용 0원: 외부 유료 서비스·API 키 금지. 외부 CDN·웹폰트도 쓰지 않음(오프라인·차단 환경에서도 같은 화면 — 시스템 폰트).
- 수정 금지 파일: `.claude/` `.codex/` `.agents/` `.gitignore` `README.md` `01_참가자_배포용/` `Dockerfile` `axhub.yaml`.

## 팀 구성 (실제 하위 에이전트)
| 담당 | 실행 주체 | 범위 | 산출물 | 완료 기준 |
|---|---|---|---|---|
| 팀장 | 주 에이전트 | 일정·통합·배포, **디자인·효과 검수** | `docs/design/팀장_검수.md` | 검수 기준 충족 판정 |
| 디자인팀 | 하위 에이전트 | 현재 화면 진단, 디자인 명세(색·글꼴·간격·컴포넌트·각 탭 레이아웃·상태 표현·반응형·접근성) | `docs/design/디자인_명세.md` | 코딩팀이 그대로 구현 가능한 수준 |
| 코딩팀 | 하위 에이전트 | 명세 구현(`public/` 위주), 테스터 결함 수정 | 커밋 | npm test 통과, 명세 반영, 결함 수정 |
| 테스터팀 | 하위 에이전트 | 기준선 점검 → 구현 후 화면·기능·회귀·반응형·접근성 테스트, 결과 보고 | `docs/design/테스트_보고서.md` | 결함 0건(높음·중간) 또는 수정 확인 |
| PM | 하위 에이전트(마지막 투입) | 사용자 요구·대회 요구 대비 최종 검수, 사용자 보고안 | `docs/design/PM_최종검수.md` | 승인 |

## 흐름
디자인 명세 ∥ 테스터 기준선 → 코딩 구현 → 테스터 테스트 → (결함 시) 코딩 수정 → 테스터 재검증 → 팀장 디자인·효과 검수 → (반려 시 반복) → PM 최종 검수 → 배포 → 배포본 확인 → 사용자 제출.

## 공용 환경
- 로컬 미리보기: http://localhost:3500 (팀장이 실행, 상태 파일 /tmp/axwar_preview_state.json — 실서비스 상태와 분리). 앱 내 브라우저로 열 수 있음. 브라우저는 각자 `tabs_create`로 자기 탭에서만 사용.
- 영역: `docs/design/디자인_명세.md`=디자인팀, `public/`·`server.js`(정적 제공 부분만)=코딩팀, `docs/design/테스트_보고서.md`=테스터팀.

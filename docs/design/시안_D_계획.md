# 시안 D 계획 — "출하 판정 라벨" (2026-11-12)

지침: Anthropic 공식 frontend-design 플러그인(SKILL.md). 로컬 미리보기 전용, 배포 안 함.

## 1. 무엇을 위한 화면인가
- 대상: 더마 화장품 공장 품질보증팀, 품질위원회. 회수 결정과 공급 복구를 다룬다.
- 주된 일: 어느 배치가 왜 회수 대상인지, 지금 누구의 결정이 필요한지를 한눈에 보여 주는 것.
- 업계의 시각 언어: GMP 창고 팔레트에 붙는 **상태 표시 라벨**(합격 초록, 보류 노랑, 불합격 빨강 스티커), 시험성적서, 배치 기록서의 서명란.

## 2. 디자인 토큰
| 이름 | 값 | 용도 |
|---|---|---|
| 기록지 | `#F6F7F5` | 바탕. 크림색이 아니라 차가운 회백색 |
| 백지 | `#FFFFFF` | 표·패널 |
| 잉크 | `#1F2B2A` | 본문. 순수 검정 대신 녹회색 잉크 |
| 검인 녹청 | `#0E5E58` | 주 버튼과 활성 탭 (유일한 강조색) |
| 회수 라벨 | `#C2261C` | 회수 대상에만 사용 |
| 보류 라벨 | `#E2A11B` | 분모 민감·주의 |

- 글꼴: 시스템 글꼴 한 가지(맑은 고딕 계열, 비용 0원 원칙상 웹폰트 없음). 위계는 크기와 굵기로만 만들고, 숫자는 고정폭 숫자를 쓴다.
- 배치: 왼쪽 정렬. 카드 묶음 대신 "흰 기록지 + 1px 선" 한 종류의 그릇만 쓴다. 그림자는 쓰지 않는다.

```
┌ 품질 회수·공급 복구 ─────────────── [기준일 2026-07-01] [확장] [초기화] ┐   ← 밝은 머리, 잉크 밑줄
├ 대시보드  사건  이벤트 …                                                ┤
│ ▌회수 대상 2 │ 분모 민감 0 │ 예방 점검 2 │ 조사 65 │ 미달 17 │ 정상 394 │   ← 한 줄 집계 띠
│  (빨간 라벨만 강하게, 나머지는 조용히)                                       │
│ 표: 판정 열의 칩 = 창고 상태 라벨(직사각형, 왼쪽 색 띠, 굵은 글자)             │
```

## 3. 원칙
1. **눈에 띄는 것은 한 곳뿐**: 판정 칩을 창고 상태 라벨처럼 만든다. 집계 띠에서는 '회수 대상'만 빨간 라벨로 채운다.
2. 둥근 카드, 그림자, 알약 모양, 색 바탕 배지를 걷어낸다.
3. [원본]·[도출] 근거 태그는 작은 회색 글자로 낮춘다. 단, [모의]·[미확인]은 색 글자로 남긴다.
4. 기능, 문구, 수치는 그대로 두고 CSS만 바꾼다(`?theme=d`).

## 4. 자체 점검 (지침의 'AI 티' 목록과 대조)
| 흔한 기본값 | A안에 있었나 | D안 처리 |
|---|---|---|
| 같은 둥근 카드에 같은 그림자 반복 | KPI 6장, 시나리오·대안 카드 | 카드 → 한 줄 집계 띠, 나머지 카드는 평평한 1px 선 |
| 알약 모양 배지 남발 | 판정 칩, 기준일, 상태 칩 | 직사각형 라벨. 기준일은 도장처럼 테두리만 |
| 어두운 남색 헤더 + 금색 선 | 있음 | 밝은 머리 + 잉크 밑줄 |
| 신문형(가는 선, 각진 모서리, 빽빽한 단) | — | 위험 요소. 모서리 2px, 여백은 유지하고 단 나누기는 하지 않아 피함 |
| 아무 데나 붙는 색 강조 | 탭·버튼·태그·배지 모두 파랑 | 강조색은 버튼·활성 탭에만 |

수정한 점: 처음엔 강조색으로 남색을 생각했지만, A안과 같은 '기업 남색' 기본값이라 실험실 장부의 녹청으로 바꿨다.

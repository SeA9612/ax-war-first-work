# 테스트 보고서 — 디자인 개선 단계 (테스터팀)

- 대상: 로컬 미리보기 http://localhost:3500 (실서비스와 상태 분리), 커밋 `0ab5a6e` 기준 `public/index.html`·`style.css`·`app.js`
- 일시: 2026-11-11 · 도구: 앱 내 브라우저(자기 탭 tab-4, 종료 후 닫음), curl, `npm test`, JS로 DOM 측정
- 원칙: 코드 무수정, 실제 AI 호출·API 키 없음(비용 0원). 종료 시 `POST /api/reset` 실행 완료.
- 확인창(`confirm`) 처리: 브라우저 자동화가 대화상자에서 멈추지 않도록 테스트 탭 안에서만 `window.confirm`을 대체해 **문구가 뜨는지·취소 시 동작하지 않는지·확인 시 동작하는지**를 검사함(실제 대화상자 모양은 확인하지 않음).
- 측정 한계: 앱 내 브라우저 창이 약 760px 폭이라 1440 폭은 화면 축소 렌더링으로만 볼 수 있어, 1440 결과는 DOM 수치(열 너비·scrollWidth) 위주로 기록. 768·375는 스크린샷과 수치를 함께 기록.

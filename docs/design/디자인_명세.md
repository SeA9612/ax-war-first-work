### 1.2 잘 되어 있어 유지할 점
- 상태가 항상 **글자**로 쓰여 있어(색만으로 전달하지 않음) 기본 바탕은 좋다. 체크 결과도 `✓/✗`와 `충족/미충족` 글자가 있다.
- 숫자 열 오른쪽 정렬·`tabular-nums` 적용, 기준일 노란 배지, 공유 환경 띠는 의도가 분명하다.
- 남색 헤더 + 밝은 본문의 업무용 톤은 유지한다.

## 2. 디자인 방향

- **업무용 운영 대시보드**: 차분한 중립 회색 바탕, 흰 카드, 색은 "의미가 있을 때만". 장식 그라데이션·그림자 과다·아이콘 폰트·일러스트 금지.
- **움직임 최소**: 전환은 `150ms ease-out`의 색·배경·테두리 변화만. 펼침/접힘·탭 전환에 슬라이드·페이드 애니메이션 금지. `prefers-reduced-motion: reduce`이면 전환 0ms, `scrollIntoView`는 `behavior:'auto'`.
- **시스템 폰트만**(외부 폰트·CDN 금지): `font-family: system-ui, -apple-system, "Segoe UI", "Malgun Gothic", "맑은 고딕", "Apple SD Gothic Neo", "Noto Sans KR", sans-serif;` 숫자 강조는 같은 글꼴에 `font-variant-numeric: tabular-nums`.
- **시연 우선**: 1080p 녹화에서 읽히도록 본문 15px, 보조 최소 13px, 칩·태그 최소 12px(굵게). 핵심 숫자는 크게(요약 28px).
- **세 가지 시각 언어를 분리**: ① 배치 판정(채운 알약 칩) ② 처리 상태(테두리 알약 칩 + 점) ③ 근거·실행 구분(네모 태그). 모양으로 먼저 구분되고 색은 보조.

### 3.3 색 — 처리 상태 (테두리 알약 칩 + 색 점, 흰 바탕)
처리 상태(사건·작업·계획·상신·확인요청)는 **흰 바탕 + 1px 테두리 + 왼쪽 8px 점**으로 그려 판정 칩과 모양이 다르다.

| 묶음 | 해당 상태 문자열(서버 값 그대로) | 점·테두리 | 글자 |
|---|---|---|---|
| 시작·대기 `.p-wait` | 접수, 판정 완료, 대기, 확인 대기 | `#8a94a6` | `#3d4757` |
| 진행 중 `.p-active` | 위원회 상신, 상신, 재공급 계획 상신, 진행, 복구 진행, 계산 완료, 회신 대기 | `#2457c5` | `#1f4fae` |
| 결정됨(긍정) `.p-done` | 회수 의결, 재공급 승인, 승인, 완료, 회신 완료, 정상화 완료 | `#2f8f55` | `#17663a` |
| 주의·되돌림 `.p-attn` | 보류(추가자료), 재검증 필요, 거절(조사 계속), 반려 | `#d27a00` | `#8a4b00` |
| 종료(무효) `.p-cancel` | 취소 | `#9aa3b2` | `#5a6474` + 취소선 | 

- `취소`는 글자 #5a6474(5.9:1)로 올리고 취소선 유지(D10 해결).
- `회수 의결`은 "결정됨"이지만 회수 결정이라는 무게를 위해 점만 `#d93a32`(빨강) 예외 허용.
- 매핑에 없는 문자열은 `.p-wait`.
- `statusChip(s)`는 판정 6종이면 `j-*`, 그 외는 `p-*`를 반환. **판정 문자열 집합**: `회수 대상, 분모 민감, 예방 점검, 조사·소명, 정상(기준 미달), 정상`.

- 헤더의 `#aiBadge`(모의 AI 배지)도 `.run-ai` 스타일로 통일(헤더 위에서는 바탕 `#efeafd` 유지).
- `.ailabel`("AI 초안 — 판정·상태를 바꾸지 않음")도 `.run-ai` 계열(보라)로 바꾼다. 분홍은 오직 "모의 입력/처리"에만.

### 3.5 간격·모서리·그림자·글꼴 크기
```css
:root {
  --sp-1: 4px; --sp-2: 8px; --sp-3: 12px; --sp-4: 16px; --sp-5: 24px; --sp-6: 32px;
  --r-sm: 3px;   /* 태그 */
  --r-md: 6px;   /* 버튼·입력 */
  --r-lg: 10px;  /* 카드·패널 */
  --r-pill: 999px; /* 칩 */
  --shadow-1: 0 1px 2px rgba(16,24,40,.06);           /* 카드 */
  --shadow-2: 0 4px 16px rgba(16,24,40,.18);          /* 토스트 */
  --fs-xs: 12px;  /* 태그·칩 (굵기 600) — 최솟값 */
  --fs-sm: 13px;  /* 보조 설명(.small), 표 보조 */
  --fs-md: 15px;  /* 본문·표 */
  --fs-lg: 17px;  /* 패널 제목 h3 */
  --fs-xl: 21px;  /* 탭 제목 h2 */
  --fs-kpi: 28px; /* 요약 숫자 */
  --lh: 1.55;     /* 본문 줄간격 (표는 1.45) */
  --dur: 150ms;
}
```
- 12px 미만 글자 금지(현재 11px 태그 폐지).
- 패널 안 여백 `--sp-4`, 패널 사이 `--sp-4`, 섹션(h2) 위 `--sp-5`.

### 3.6 다크모드
이번 범위 **제외**(시연은 밝은 화면 기준, 위험 대비 효과 낮음). 추후 할 경우 `@media (prefers-color-scheme: dark)`에서 §3.1~3.4 변수만 재정의하고 컴포넌트 CSS는 손대지 않는다. 그래서 **컴포넌트 CSS에 색 값 직접 쓰기 금지**(모두 변수 참조).

## 4. 컴포넌트 규칙

### 4.1 헤더 (`header.top`)
- 1줄 구성(≥1024): 왼쪽 [제목 17px 굵게 + 부제 13px `W03 · Corevia PL-02 더마` + 기준일 배지], 오른쪽 [모의 AI 배지 · 확장 토글 · 초기화].
- 기준일 배지는 제목과 **같은 줄**(현재는 아래 줄) — 13px 굵게, `--basedate-bg`.
- 확장 토글: 체크박스를 스위치 모양으로 보이되 `<input type="checkbox">` 유지(기능·id 불변). 상태 글자 `ON`/`OFF`를 라벨 뒤에 붙여 색 없이도 읽히게: `확장(a) 로트 추적 · ON`. (§4.3 추가 문구)
- `초기화`: 보조(테두리) 버튼, 헤더 위에서는 흰 테두리·흰 글자, `white-space:nowrap`. 위험 동작이지만 시연 시작 버튼이라 빨강 대신 테두리 유지(확인창 있음).
- 공유 환경 띠(`.shared`): 문구 그대로, 13px, 앞에 `⚠` 기호(장식, `aria-hidden`). 
- 헤더는 `position: sticky; top:0` **하지 않음**(영상 화면 높이 확보). 탭 바만 sticky(§4.2).

### 4.2 탭 (`nav.tabs`)
- 마크업: `<nav class="tabs" id="tabs" role="tablist" aria-label="화면">`, 각 버튼 `role="tab" aria-selected="true|false"`, `main`에 `role="tabpanel"`. `render()`에서 `aria-selected` 갱신.
- 한 줄 유지: `flex-wrap: nowrap; overflow-x: auto; scrollbar-width: thin;` 모든 폭에서 줄바꿈 없음(D8①). 활성 탭이 화면 밖이면 `scrollIntoView({inline:'nearest', block:'nearest'})`.
- `position: sticky; top: 0; z-index: 5;` 흰 바탕 + 아래 1px `--line`.
- 탭 글자 15px, 높이 44px(터치 대상 최소), 활성: `--accent` 글자·굵게·아래 3px 막대. 비활성 `--ink-2`(현재 muted보다 진하게). hover: 바탕 `--surface-2`.
- 키보드: 좌우 화살표로 탭 이동(선택 사항, 낮음). Tab 키 포커스 시 포커스 링 표시.

### 4.3 카드·패널
- `.panel`: 흰 바탕, 1px `--line`, `--r-lg`, `--shadow-1`, 안 여백 16px. **`overflow-x:auto` 제거**(가로 스크롤은 `.table-wrap`에서만, D8⑤).
- 패널 머리(`.panel-head`): `h3`(17px, 위 여백 0) + 오른쪽에 실행 구분 태그·보조 정보. 인라인 `style="margin-top:0"`은 모두 클래스로 대체(`.panel > h3:first-child{margin-top:0}`).
- 요약 카드(`.kpi`): 왼쪽 4px 색 막대(해당 판정의 테두리색), 위에 라벨(칩 아님, 14px 굵게 `--ink-2` + 앞 기호), 아래 숫자 28px 굵게. 클릭 가능하면 `button` 요소로.

### 4.4 표
- 래퍼 `.table-wrap { overflow-x:auto; }`로 감싸고 표에 `min-width`(표별 지정, §5) → 좁은 폭에서 열이 찌그러지지 않고 가로 스크롤.
- 글자 15px(보조열 13px), 행 높이 최소 40px, 머리 `--surface-2` 바탕·`--ink-2` 13px 굵게·줄바꿈 허용, 아래 테두리 `--line`.
- ID·배치·날짜·숫자 셀 `white-space:nowrap`(D8④). 숫자 `.num` 오른쪽 정렬·tabular-nums 유지.
- 첫 열 고정(`position:sticky; left:0; background:inherit`)은 배치 목록·작업·대안 상세 표에만.
- 행 hover `--surface-2`. 짝수 줄 줄무늬 없음.
- 강조 행: 회수 대상 배치 행은 첫 칸 왼쪽 3px `#d93a32` 막대, 예방 점검 행은 `#1b97a6` 막대(색 + 칩 글자 이중).
- `.scroll`(높이 제한)은 **감사기록(720px)·이벤트 기록·사건 타임라인(400px)·배치 목록(560px)** 에만. **작업 표·근거 표·대안 표는 높이 제한 없음**(D9). 높이 제한 표는 `thead th{position:sticky;top:0}` 유지.

### 4.5 칩·태그
- 판정 칩 `.chip.j-*`: 높이 24px, 좌우 10px, 12~13px 굵게(600), `--r-pill`, 앞 기호.
- 처리 칩 `.chip.p-*`: 흰 바탕, 1px 테두리(해당 색), 앞 8px 원 점(`::before` 원형, 장식), 글자 13px 600.
- 근거·실행 태그 `.tag.*`: 높이 20px, 좌우 6px, 12px 600, `--r-sm`, 대괄호 포함한 원 글자 그대로 표시.
- **근거 태그 자동 표시(`tagify`)**: 서버 문자열 안의 `[원본…]`, `[도출…]`, `[가정…]`, `[모의…]`, `[미확인…]`, `[추정…]`(→ `.ev-asm`)를 `esc()` 후 정규식으로 `<span class="tag ev-*">…</span>`로 감싼다. 글자 내용은 바꾸지 않는다. 적용 범위: 표의 근거·설명 열, 입력·가정 값, 작업 제목, 시나리오 단계 제목·요약, 경고 문구.
  - 정규식 예: `/\[(원본|도출|가정|모의|미확인|추정)([^\]]*)\]/g`
- 시나리오·작업 문구 속 `(모의)`, `발송[모의]`는 `.ev-mock`과 같은 모양으로 감싼다.

### 4.7 입력

- 사건 상세의 타임라인은 표 대신 세로 목록(최신 위): 왼쪽 시각(13px, nowrap) · 가운데 2px 세로선과 8px 점 · 오른쪽 [주체 칩(작게)] 행위(굵게) + 내용(13px). 주체가 `모의 AI`면 점·주체 칩을 `.run-ai` 색, `[모의]` 입력이면 `.run-mock` 색, 그 외 회색 점.
- 높이 400px 스크롤(최근 것부터 보이므로 잘려도 무방). 감사기록 탭은 표 유지(검색·비교용).

### 4.10 단계 진행 표시 (스텝퍼)
두 곳에 같은 컴포넌트 `.stepper`를 쓴다: ①사건 상태 흐름(가로) ②시연 시나리오 단계(세로).
- 각 단계: 원(24px, 번호 또는 기호) + 이름. 상태 3가지:
  - 완료: 초록 채운 원 + `✓`, 이름 `--ink`.
  - 현재/다음: `--accent` 2px 테두리 원 + 번호, 이름 굵게 + 옆에 글자 표식 **"현재"**(사건) / **"다음"**(시나리오). (§4.3 추가 문구)
  - 대기: 회색 테두리 원 + 번호, 이름 `--muted`.
  - 분기·되돌림(보류/거절/재검증 필요): 주황 원 + `!`, 이름 옆 실제 상태 글자.
- 연결선: 완료 구간 초록 2px, 나머지 회색 2px.
- `aria-current="step"`을 현재 단계에.

## 5. 탭별 레이아웃 개선

### 5.1 대시보드
```
[h2 배치 판정 현황  · run-real "[실제 작동]" · 보조문구(기존)]
┌ 주의 묶음 ───────────────────────────────┐ ┌ 정상 묶음 ─────────────────┐
│ ▲회수 대상 2 │ ◆분모 민감 0 │ ◇예방 점검 2 │ │ ●조사·소명 65 │ ○기준 미달 17 │ ✓정상 394 │
└──────────────────────────────────────────┘ └────────────────────────────┘
  전체 480개 배치 기준 (작게)
[경고 4건]  ⚠ 보류 배치 출하 2건  /  ⚠ 회수 대상인데 사건 미접수 2건   (목록)

```
- 요약: 6개 카드를 두 묶음으로. 주의 묶음 3장은 큰 카드(숫자 28px, 왼쪽 색 막대 4px, 값이 0이 아니면 바탕 해당 판정의 연한 바탕), 정상 묶음 3장은 작은 카드(숫자 22px, 흰 바탕). 라벨은 칩 대신 "기호 + 상태명" 글자.
- 1440: 6열 한 줄(주의 3 = 각 1.3fr, 정상 3 = 각 1fr). 768: 3열 × 2줄. 375: 2열 × 3줄(D8②).
- "전체 480개 배치 기준"은 `J.total`로 표시(추가 문구).
- 경고: 패널 머리 `경고 N건`(N 추가), 각 경고 `.warnbox`. 같은 종류(문구에 "보류"/"사건 미접수" 포함)는 연속 배치만 — 문구 그대로.
- 확장 ON/OFF 안내 줄: 기존 문구 유지, `ON`/`OFF`를 처리 칩 모양으로.
- 배치 목록: 표 `min-width: 1100px`, 첫 열(배치) 고정, 배치 ID nowrap, `.scroll` 높이 560px. `회수 대상 배치로 사건 접수` 버튼은 주 버튼, 패널 머리 오른쪽 정렬. 체크박스 라벨은 `for` 연결.
- 품질 판정 `보류` + `보류 출하` 칩: 칩을 `.p-attn`(주의) 모양으로(현재 분모 민감 칩과 같은 색이라 혼동 — D3).
- 배치 상세(클릭 시 아래 표시): 패널 머리 "B-…상세" + 판정 칩, 두 표 나란히(768 이하 세로). `scrollIntoView`는 `behavior:'auto'` 또는 reduced-motion 존중.
